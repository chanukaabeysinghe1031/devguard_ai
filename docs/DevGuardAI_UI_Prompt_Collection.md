## Prompt Template

For each screen, prepend the Global Design System, then describe only
that screen.

### Login

Create a premium login page with AI illustration, glass login card,
logo, email, password, remember me, forgot password, Sign In button and
Create Account link.

### Dashboard

Create KPI cards, recent incidents table, severity donut chart, incident
trend line chart, top failure categories and activity feed.

### Projects

Project list with search, filters, cloud provider, CI provider, health
and open incidents.

### Create Project

Four-step wizard: Details, Repository, Cloud, Review.

### Project Details

Statistics cards, pipeline history, incidents and tabs.

### Incident List

Searchable incident table with filters, severity, status and confidence.

### Create Incident

Wizard with upload area and Start AI Analysis button.

### Upload Files

Drag-and-drop upload interface with validation and secret masking
status.

### AI Analysis

Progress circle, stages and ETA.

### Incident Details

Root cause, confidence, tabs, quick actions and summary.

### Evidence

Evidence list and VS Code-style log viewer.

### Recommendations

Recommendation cards grouped by fix, verification and prevention.

### Timeline

Vertical activity timeline.

### Notes

Discussion page with markdown comments.

### Resolution

Guided resolution wizard.

### Reports

Report library with Generate Report.

### History

Searchable incident history.

### Notifications

Modern notification center.

### Global Search

Spotlight search overlay.

### Settings

Profile, appearance, notifications, AI and security tabs.

### User Profile

Avatar, activity and account settings.

### Admin Users

User management table.

### AI Models

Model management dashboard.

### Evaluation

ML metrics dashboard.

### System Health

Infrastructure monitoring dashboard.

### Empty States

Elegant empty states.

### Error States

Professional error pages.

### Design System

Complete UI component library.

Generate the Design System screen first and use it as the reference
image for all other screens.
